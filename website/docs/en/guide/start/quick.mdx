# Quick Start

This guide walks you through the core workflow of `@praha/byethrow` in a few minutes.

## Installation

Install the package with your preferred package manager:

<PackageManagerTabs command="install @praha/byethrow" />

## Your First `Result`

A `Result` is either a **Success** that holds a value, or a **Failure** that holds an error.
Create them with `Result.succeed` and `Result.fail`, and return them instead of throwing:

```ts
import { Result } from '@praha/byethrow';

const divide = (a: number, b: number) => {
  if (b === 0) {
    return Result.fail(new Error('Cannot divide by zero'));
  }
  return Result.succeed(a / b);
};
```

To read the contents, first check which variant you have with `Result.isSuccess` or `Result.isFailure`.
TypeScript then knows whether `value` or `error` is available:

```ts
import { Result } from '@praha/byethrow';

declare const divide: (a: number, b: number) => Result.Result<number, Error>;
// ---cut-before---
const result = divide(10, 2);

if (Result.isSuccess(result)) {
  console.log(result.value); // 5
} else {
  console.error(result.error.message);
}
```

## Wrapping Code That Throws

Existing code, built-in APIs, and third-party libraries often throw.
`Result.fn` wraps such a function so that it returns a `Result` instead:

```ts
import { Result } from '@praha/byethrow';

const parseJson = Result.fn({
  try: (text: string) => JSON.parse(text) as unknown,
  catch: (error) => new Error('Invalid JSON', { cause: error }),
});

parseJson('{"name": "Alice"}');
// { type: 'Success', value: { name: 'Alice' } }

parseJson('not json');
// { type: 'Failure', error: Error('Invalid JSON') }
```

## Composing Steps with `pipe`

`Result.pipe` passes a value through a series of steps from top to bottom.
Use `Result.andThen` for steps that can fail (they return a `Result`), and `Result.map` for steps that simply transform the value:

```ts
import { Result } from '@praha/byethrow';

const validateId = (id: string) => {
  if (!id.startsWith('u')) {
    return Result.fail(new Error('Invalid ID format'));
  }
  return Result.succeed(id);
};

const findUser = (id: string) => {
  if (id !== 'u123') {
    return Result.fail(new Error('User not found'));
  }
  return Result.succeed({ id, name: 'John Doe' });
};

const welcome = (id: string) => Result.pipe(
  Result.succeed(id),
  Result.andThen(validateId),
  Result.andThen(findUser),
  Result.map((user) => `Welcome, ${user.name}!`),
);

welcome('u123');
// { type: 'Success', value: 'Welcome, John Doe!' }

welcome('x999');
// { type: 'Failure', error: Error('Invalid ID format') }
```

As soon as a step fails, the remaining steps are skipped and the failure is passed straight to the end of the pipeline.
You don't need to check for errors after every step.

## Recovering from Failures

Use `Result.orElse` to handle a failure and continue with a fallback:

```ts
import { Result } from '@praha/byethrow';

declare const welcome: (id: string) => Result.Result<string, Error>;
// ---cut-before---
const result = Result.pipe(
  welcome('x999'),
  Result.orElse(() => Result.succeed('Welcome, guest!')),
);
// { type: 'Success', value: 'Welcome, guest!' }
```

## Working with Async Operations

Async functions work with exactly the same API.
When any step returns a `Promise`, the whole pipeline becomes asynchronous, so just `await` the result:

```ts
import { Result } from '@praha/byethrow';

type User = { id: string; name: string };

declare const validateId: (id: string) => Result.Result<string, Error>;
// ---cut-before---
const fetchUser = Result.fn({
  try: async (id: string) => {
    const response = await fetch(`/api/users/${id}`);
    return await response.json() as User;
  },
  catch: (error) => new Error('Failed to fetch user', { cause: error }),
});

const result = await Result.pipe(
  Result.succeed('u123'),
  Result.andThen(validateId), // sync
  Result.andThen(fetchUser),  // async
  Result.map((user) => user.name),
);
// Type: Result.Result<string, Error>
```
