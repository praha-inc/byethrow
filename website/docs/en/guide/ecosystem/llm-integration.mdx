# LLM Integration

AI assistants often don't know about byethrow, or only know an outdated version of its API.
byethrow provides its documentation in forms that assistants can read, so that they can give accurate guidance for your code.

## Agent Skills (Recommended)

The `@praha/byethrow-docs` package bundles the complete documentation as Markdown files, together with a CLI that sets up your AI assistant to use them.
This is the recommended approach, because:

- The documentation is stored in your project, so it works offline without any server.
- Its version always matches the version of `@praha/byethrow` you install.
- The assistant can search the documentation and read only the parts it needs.

### Installation

Install the package as a development dependency, using the same version as `@praha/byethrow`:

<PackageManagerTabs command="install -D @praha/byethrow-docs" />

### Setup

Run the `init` command for your AI assistant.
It creates a configuration file that tells the assistant where the documentation is and how to search it:

```bash
# Claude Code (creates .claude/skills/byethrow/SKILL.md)
npx @praha/byethrow-docs init claude

# GitHub Copilot (creates .github/skills/byethrow/SKILL.md)
npx @praha/byethrow-docs init copilot

# Cursor (creates .cursor/rules/byethrow/RULE.md)
npx @praha/byethrow-docs init cursor
```

Commit the generated file so that everyone on your team gets the same setup.
From then on, the assistant consults the byethrow documentation whenever it works on related code.

### CLI Commands

The assistant uses the following commands to explore the documentation. You can also run them yourself:

```bash
# List all available documents
npx @praha/byethrow-docs list

# List documents matching a keyword
npx @praha/byethrow-docs list --query "pipe"

# Search the documentation (up to 5 results by default)
npx @praha/byethrow-docs search "your query" --limit 10

# Show the table of contents of a document
npx @praha/byethrow-docs toc path/to/document.md
```

## llms.txt

This website also publishes its content following the [llms.txt](https://llmstxt.org/) convention.
Pass these URLs to an assistant that can read web pages:

| URL                                                                                                      | Content                                        |
|----------------------------------------------------------------------------------------------------------|------------------------------------------------|
| [https://praha-inc.github.io/byethrow/llms.txt](https://praha-inc.github.io/byethrow/llms.txt)           | An index of all pages with short descriptions  |
| [https://praha-inc.github.io/byethrow/llms-full.txt](https://praha-inc.github.io/byethrow/llms-full.txt) | The full content of all pages in a single file |

Every page is also available as Markdown by adding `.md` to its URL, for example [https://praha-inc.github.io/byethrow/guide/start/quick.md](https://praha-inc.github.io/byethrow/guide/start/quick.md).
