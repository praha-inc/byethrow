# Parse package.json <SourceCode href="https://github.com/praha-inc/byethrow/tree/main/examples/parse-package-json" />

This example reads the `package.json` file in the current directory, validates its contents, and prints the package name and version.
Every step that can fail returns a `Result`, and each kind of failure is reported with its own message.

## What This Example Shows

- **Wrapping Node.js APIs**: `readFile` wraps `fs.readFile` with [`Result.fn`](../guide/tutorial/basics/wrapping-functions) and converts file system errors into a `ReadFileError`.
- **Parsing and validation**: `parsePackageJson` parses the text with `Result.try` and validates it against a Zod schema with [`Result.parse`](../guide/tutorial/basics/parsing-values). Any failure is converted into a `ParsePackageJsonError` with `Result.mapError`.
- **Composing steps**: The entry point chains both steps with `Result.pipe` and `Result.andThen`.
- **Handling the outcome**: `Result.inspect` prints the result, while `Result.inspectError` uses [`ts-pattern`](../guide/best-practices/pattern-matching) to print a message for each error type and sets the exit code.
- **Testing**: The tests assert results with the matchers from [`@praha/byethrow-testing`](../guide/ecosystem/testing).
