# オブジェクトを構築する

それぞれ失敗しうる処理から得られる複数の値が必要で、しかも後のステップが前のステップの結果に依存していることがあります。
`do` / `bind` / `let` パターンを使うと、こうした値を 1 フィールドずつひとつのオブジェクトにまとめられます。

## `do` から始める

`do` は空のオブジェクトを持つ `Success` を作成します。これがこのパターンの出発点です。

```ts
import { Result } from '@praha/byethrow';

const start = Result.do();
// { type: 'Success', value: {} }
```

## `bind` でフィールドを追加する

<ResultFlow fn="bind" />

`bind(name, fn)` は、蓄積されたオブジェクトにフィールドを追加します。

1. それまでに蓄積されたオブジェクトを引数に `fn` を呼び出します。
2. `fn` が `Success` を返した場合、その値を `name` というキーでオブジェクトに追加します。
3. `fn` が `Failure` を返した場合、パイプラインはそこで停止し、その `Failure` が返されます。

```ts
import { Result } from '@praha/byethrow';

const result = Result.pipe(
  Result.do(),
  Result.bind('name', () => Result.succeed('Alice')),
  Result.bind('age', () => Result.succeed(30)),
);
// { type: 'Success', value: { name: 'Alice', age: 30 } }
```

### 前の値を利用する

`bind` の重要な特徴は、各ステップがそれより前に追加されたフィールドを利用できることです。

```ts
declare const fetchUser: (userId: string) => Result.ResultAsync<{ id: string; profileId: string }, 'UserNotFound'>;
declare const fetchProfile: (profileId: string) => Result.ResultAsync<{ bio: string }, 'ProfileNotFound'>;
// ---cut-before---
import { Result } from '@praha/byethrow';

const result = await Result.pipe(
  Result.do(),
  Result.bind('user', () => fetchUser('u123')),
  Result.bind('profile', ({ user }) => fetchProfile(user.profileId)), // `user` を利用
);
// 型: Result.Result<{ user: { id: string; profileId: string }; profile: { bio: string } }, 'UserNotFound' | 'ProfileNotFound'>
```

### 失敗すると短絡する

いずれかの `bind` が失敗すると、残りのステップはスキップされます。

```ts
import { Result } from '@praha/byethrow';

const result = Result.pipe(
  Result.do(),
  Result.bind('a', () => Result.succeed(1)),
  Result.bind('b', () => Result.fail('Error!')), // ここで失敗
  Result.bind('c', () => Result.succeed(3)),     // スキップされる
);
// { type: 'Failure', error: 'Error!' }
```

## `let` で通常の値を追加する

<ResultFlow fn="let" />

フィールドの中には、それまでに追加されたフィールドから計算でき、失敗することのないものもあります。
`let(name, fn)` は `fn` が返した値をそのまま追加するため、`succeed` で包む必要がありません。

```ts
import { Result } from '@praha/byethrow';

const result = Result.pipe(
  Result.do(),
  Result.bind('price', () => Result.succeed(1000)),
  Result.bind('quantity', () => Result.succeed(3)),
  Result.let('total', ({ price, quantity }) => price * quantity),
);
// { type: 'Success', value: { price: 1000, quantity: 3, total: 3000 } }
```

これは `Result.bind('total', ({ price, quantity }) => Result.succeed(price * quantity))` と同じですが、そのステップが失敗しないことがひと目でわかります。

:::info
`let` は `Promise` を自動で await せず、失敗を表現する手段も持ちません。
値が非同期処理や失敗しうる処理から得られる場合は、`Result` または `ResultAsync` を返す関数とともに `bind` を使ってください。
:::

## 例：関連データを取得する

あるデータを取得するために別のデータが必要な場合でも、`bind` を使えば途中の値をすべて最後まで利用できます。

```ts
declare const fetchOrder: (orderId: string) => Result.ResultAsync<{ id: string; userId: string; productIds: string[] }, 'OrderNotFound'>;
declare const fetchUser: (userId: string) => Result.ResultAsync<{ id: string; name: string }, 'UserNotFound'>;
declare const fetchProducts: (productIds: string[]) => Result.ResultAsync<{ id: string; name: string; price: number }[], 'ProductNotFound'>;
// ---cut-before---
import { Result } from '@praha/byethrow';

type OrderDetails = {
  orderId: string;
  customerName: string;
  products: { id: string; name: string; price: number }[];
  totalPrice: number;
};

const getOrderDetails = (orderId: string): Result.ResultAsync<OrderDetails, 'OrderNotFound' | 'UserNotFound' | 'ProductNotFound'> => {
  return Result.pipe(
    Result.do(),
    Result.bind('order', () => fetchOrder(orderId)),
    Result.bind('user', ({ order }) => fetchUser(order.userId)),
    Result.bind('products', ({ order }) => fetchProducts(order.productIds)),
    Result.map(({ order, user, products }) => ({
      orderId: order.id,
      customerName: user.name,
      products,
      totalPrice: products.reduce((sum, product) => sum + product.price, 0),
    })),
  );
};
```

:::tip
`bind` はステップを 1 つずつ順番に実行します。これは、あるステップが前のステップに依存している場合に必要な動作です。
処理同士が互いに独立している場合は、[次のページ](./aggregating-results)で紹介する `sequence` や `collect` の方が適しています。`collect` なら非同期処理を並列に実行することもできます。
:::
