## 最初の `Result`

`Result` は、値を持つ **Success**（成功）か、エラーを持つ **Failure**（失敗）のどちらかです。
`Result.succeed` と `Result.fail` で作成し、例外を投げる代わりに関数から返します。

```ts
import { Result } from '@praha/byethrow';

const divide = (a: number, b: number) => {
  if (b === 0) {
    return Result.fail(new Error('Cannot divide by zero'));
  }
  return Result.succeed(a / b);
};
```

中身を読み取るには、まず `Result.isSuccess` または `Result.isFailure` でどちらの状態かを確認します。
すると TypeScript は、`value` と `error` のどちらが使えるかを判断できます。

```ts
import { Result } from '@praha/byethrow';

declare const divide: (a: number, b: number) => Result.Result<number, Error>;
// ---cut-before---
const result = divide(10, 2);

if (Result.isSuccess(result)) {
  console.log(result.value); // 5
} else {
  console.error(result.error.message);
}
```

## 例外を投げるコードをラップする

既存のコード、組み込み API、サードパーティのライブラリは例外を投げることがよくあります。
`Result.fn` でそのような関数をラップすると、代わりに `Result` を返す関数になります。

```ts
import { Result } from '@praha/byethrow';

const parseJson = Result.fn({
  try: (text: string) => JSON.parse(text) as unknown,
  catch: (error) => new Error('Invalid JSON', { cause: error }),
});

parseJson('{"name": "Alice"}');
// { type: 'Success', value: { name: 'Alice' } }

parseJson('not json');
// { type: 'Failure', error: Error('Invalid JSON') }
```

## `pipe` で処理をつなげる

`Result.pipe` は、値を一連のステップに上から順に渡していきます。
失敗する可能性のあるステップ（`Result` を返すもの）には `Result.andThen` を、値を変換するだけのステップには `Result.map` を使います。

```ts
import { Result } from '@praha/byethrow';

const validateId = (id: string) => {
  if (!id.startsWith('u')) {
    return Result.fail(new Error('Invalid ID format'));
  }
  return Result.succeed(id);
};

const findUser = (id: string) => {
  if (id !== 'u123') {
    return Result.fail(new Error('User not found'));
  }
  return Result.succeed({ id, name: 'John Doe' });
};

const welcome = (id: string) => Result.pipe(
  Result.succeed(id),
  Result.andThen(validateId),
  Result.andThen(findUser),
  Result.map((user) => `Welcome, ${user.name}!`),
);

welcome('u123');
// { type: 'Success', value: 'Welcome, John Doe!' }

welcome('x999');
// { type: 'Failure', error: Error('Invalid ID format') }
```

いずれかのステップが失敗すると、残りのステップはスキップされ、失敗はそのままパイプラインの最後まで渡されます。
ステップごとにエラーをチェックする必要はありません。

## 失敗から回復する

`Result.orElse` を使うと、失敗を処理してフォールバックの値で処理を続けられます。

```ts
import { Result } from '@praha/byethrow';

declare const welcome: (id: string) => Result.Result<string, Error>;
// ---cut-before---
const result = Result.pipe(
  welcome('x999'),
  Result.orElse(() => Result.succeed('Welcome, guest!')),
);
// { type: 'Success', value: 'Welcome, guest!' }
```

## 非同期処理を扱う

非同期関数も、まったく同じ API で扱えます。
いずれかのステップが `Promise` を返すとパイプライン全体が非同期になるので、結果を `await` するだけです。

```ts
import { Result } from '@praha/byethrow';

type User = { id: string; name: string };

declare const validateId: (id: string) => Result.Result<string, Error>;
// ---cut-before---
const fetchUser = Result.fn({
  try: async (id: string) => {
    const response = await fetch(`/api/users/${id}`);
    return await response.json() as User;
  },
  catch: (error) => new Error('Failed to fetch user', { cause: error }),
});

const result = await Result.pipe(
  Result.succeed('u123'),
  Result.andThen(validateId), // 同期
  Result.andThen(fetchUser),  // 非同期
  Result.map((user) => user.name),
);
// 型: Result.Result<string, Error>
```
